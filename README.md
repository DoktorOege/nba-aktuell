# NBA Aktuell

Inoffizielle Fan-App mit NBA-Ergebnissen, Spielplan (deutsche Zeit), Prime-Video-Terminen, Tabelle, Top-20-Spielern, Team-Kadern und News auf Deutsch.

- App: https://doktoroege.github.io/nba-aktuell/
- Daten: `data.json` (wird morgens und abends automatisch aktualisiert)
- Installierbar als Web-App (Manifest + Service Worker)

Team-Abzeichen sind eigene Gestaltungen in Vereinsfarben. Keine Verbindung zur NBA.
